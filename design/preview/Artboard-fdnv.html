HOW THE BOARDS ARE BUILT

Every board carries the Fluant Ink tokens as CSS custom properties and reproduces the system’s class contract — .fl-btn[data-variant], .fl-table td[data-numeric], .fl-switch[aria-checked] — so a port only has to emit the same markup and the same data attributes. State lives in one logic class per board; nothing is built by script.
