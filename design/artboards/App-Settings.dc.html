Danger zone

Two of these cannot be undone. Both ask you to type the project name first, because a confirmation dialog on its own is not a decision.

Pause the project

Every domain starts answering 503 and builds stop. The artifacts, traces and settings stay exactly as they are. Reversible at any time.

Delete storefront-edge

Removes 128 builds, 4 domains, every trace and the edge KV namespace. The project name becomes available to anyone immediately. There is no export afterwards.
