Motion

Durations and curves are tokens. If you cannot name what a transition explains, delete it.

DURATION

duration-instant80msColour or opacity on hover and press
duration-fast140msTooltip, switch knob, tab underline
duration-base220msMenu, popover, toast, accordion
duration-slow380msModal, drawer, tab cross-fade
duration-slower620msScroll reveal, staggered entrance
duration-cinematic1100msHero entrance, counter run. One per viewport.

EASING

ease-standardcubic-bezier(0.2,0,0,1)Moves that stay on screen
ease-entrancecubic-bezier(0.16,1,0.3,1)Anything arriving
ease-exitcubic-bezier(0.7,0,0.84,0)Anything leaving
ease-springcubic-bezier(0.34,1.56,0.64,1)One overshoot, a deliberate act
ease-anticipatecubic-bezier(0.68,-0.4,0.27,1.4)Hero and page transitions only
Animate transform and opacity. Travel is 8–24px for a reveal, 4px for a press, 100% only for a drawer. Every motion has a reduced form and each board ships the media query.
transition: transform var(--duration-base) var(--ease-standard);

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
  }
}

No literal ms and no literal cubic-bezier() in component code.
09

Porting rules

Five things that decide whether a port keeps working as the system grows.

01

The element is part of the contract

A button is a <button>, a link is an <a href>, a field is an <input> with a <label for>. Swap in a div with a click handler and the CSS still matches but Tab stops working.

02

State lives in attributes, not classes

aria-pressed, aria-selected, aria-checked, aria-current, aria-invalid, aria-expanded and disabled are what the CSS keys off. That means the accessible state and the visual state cannot drift apart — there is only one of them.

03

Variants live in data-*

data-variant, data-size, data-tone, data-dense, data-numeric. A port emits the same strings and inherits every rule, including ones added later.

04

Layout is flex or grid with gap

Never margins between siblings and never whitespace-as-spacing. Gap survives reordering, deletion and direct manipulation; margins do not.

05

Colour is never the only signal

Status carries a word, charts carry direct labels, bars that mean 'slow' also say the number. High contrast removes every shadow, so nothing may depend on one to exist.
