Build behaviour

Two switches that change every future build.

Reuse the build cache

Unchanged steps are skipped. Turn this off only to prove a build is reproducible from nothing.

Require a matching attestation

A build whose digest does not match a second independent run is refused rather than shipped.

Deploy approvals

Who has to approve before traffic moves to a new build.
