09

Porting rules

Five things that decide whether a port keeps working as the system grows.

01

The element is part of the contract

A button is a Button, a link is a Link, a field is an Input with a label. Swap in a container with a click handler and the CSS still matches but Tab stops working.

02

State lives in attributes, not classes

aria-pressed, aria-selected, aria-checked, aria-current, aria-invalid, aria-expanded and disabled are what the CSS keys off. The accessible state and the visual state cannot drift apart — there is only one of them.

03

Variants live in data-*

data-variant, data-size, data-tone, data-dense, data-numeric. A port emits the same strings and inherits every rule, including ones added later.

04

Layout is flex or grid with gap

Never margins between siblings and never whitespace-as-spacing. Gap survives reordering, deletion and direct manipulation; margins do not.

05

Colour is never the only signal

Status carries a word, charts carry direct labels, bars that mean slow also say the number. High contrast removes every shadow, so nothing may depend on one to exist.
